# Skin Disease Prediction

Machine Learning model for predicting
erythemato-squamous skin diseases.

## Algorithms Used

- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- Extra Trees
- Gradient Boosting
- XGBoost
- CatBoost
- SVM

## Best Model

Extra Trees Classifier

Accuracy: 98.65%
